# 03_AI_PIPELINE

## 6-Agent Autonomous Pipeline

1. **Plot Architect**: Defines the global structure and beats using the selected narrative framework (e.g., Hero's Journey, Save the Cat).
2. **Character Psychologist**: Analyzes the protagonist and defines behavioral arcs and motivations.
3. **Scene Composer**: Translates plot beats into localized scene settings, blocking, and action logic.
4. **Emotion Engine**: Injects visceral, sensory, and emotive text based on the active Author Persona (e.g., Weaver, NightKing).
5. **Continuity Manager**: Ensures that earlier chapters and lore (stored in Lorebook) remain consistent.
6. **Executive Orchestrator**: Manages the overarching loop, checking word counts, handling API retries, and stitching the final manuscript.
