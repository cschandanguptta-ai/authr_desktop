# ADR-0011 — One-action retail packager: epubcheck is a blocking external gate, the print ladder is verified by measurement, and the workbench owns retail metadata

**Status:** Accepted (P5)
**Context:** The plan's P5 row (§13) requires "a complete .authr project produces the full retail package in one action", with §11.3 gates: "epubcheck zero errors" for the KDP eBook export and a "KDP Print Previewer pass" for the interior. Three design tensions: (1) epubcheck is an external Java tool — embed it, or locate it and disclose when absent; (2) the KDP Previewer is Amazon-side and cannot run in CI — fake a pass, or verify the measurable contract locally and disclose the external step; (3) retail metadata could come from the Book record (with its v2.3 ISBN placeholder, D-05) or from the §11.2 workbench.
**Decision:** (1) `RetailPackager.packageRetail` is the one action: writer gate → workbench resolution → EPUB(s) (novel single / serial per-micro-arc volumes through the same exporter) → epubcheck → print interior → pricing record → ship report. epubcheck runs as an **external, blocking gate**: `EpubCheckLocator` resolves the official dist (env/app-dir/user paths, never bundled), the verdict is parsed from epubcheck's own "Messages:" summary (not the exit code — 5.x returns 1 for errors too), and a missing tool yields status UNVERIFIED with **clean = false** — the package is still produced, but the report says the zero-errors precondition is unproven. Nothing is silently green. (2) The print interior is verified **by measurement**: 6×9 in trim MediaBox, mirrored recto/verso margins, and the plan §11.1 gutter ladder applied by iterative pagination (paginate → ladder lookup → re-paginate → converge); the P5 gate drives synthetic interiors through **all four ladder bands** and asserts the resulting gutter per band. The Previewer run itself is disclosed as an upload-time human step (open question OQ-15). (3) The structured `KdpWorkbench` (container `metadata/kdp_workbench.json`, additive over the v2.3 string stub, both forms readable — openers migrate forward, never downgrade) is the **authoritative** retail-metadata source; the compiled-manuscript ISBN placeholder does not reach retail exports (resolves OQ-9).
**Alternatives considered:** embedding epubcheck as a library dependency (rejected — a ~10 MB tool plus its Saxon stack inside the app image for one gate; the locator pattern matches Ffmpeg/Espeak/Pocket precedent); trusting epubcheck exit codes (rejected — version-drifted semantics, measured by the 5.2.1 behavior in this gate); faking or estimating the Previewer pass (rejected — ADR-0010 discipline: measured, not estimated; disclose what is external); Book-record metadata as authoritative (rejected — the workbench is a first-class editing surface per plan §11.2, and the Book record has no author/keywords/pricing fields).
**Consequences:** A writer machine without epubcheck cannot produce a clean ship report (the report says exactly why — distribution story is OQ-16); `RetailPackager.runEpubCheck` couples the verdict format to epubcheck's summary line (version-coupled like D-14 — same mitigation shape: loud RED, never silent); the packager is engine-only until D-15 lands (no UI call site yet, pdfbox dependency not yet in `build.gradle.kts`); the ArcPayload now carries the arc id so chapters' `arcId` joins survive container round-trips (additive, default 0).
**Do not change unless:** the plan's §11/§13 contract changes, or epubcheck's summary format moves (then re-pin the parser with a measured sample, as D-14 prescribes for ffmpeg).
**Evidence:** `engine/publishing/RetailPackager.kt` (packageRetail order of operations, runEpubCheck summary parsing), `engine/publishing/PrintInterior.kt` (ladder + iterative pagination), `engine/publishing/PublishingMetadata.kt` (authority rule), `container/AuthrContainer.kt` (structured workbench, additive ArcPayload.id), `scripts/p5_gate.sh`, gate log 2026-11-11 (`download/Authr-OS-3.0-P5-Retail-Package/gate-report.md`: epubcheck v5.2.1 zero errors on novel + 2 volumes; bands 85/206/389/571 pages → 0.375/0.5/0.625/0.75 in).
